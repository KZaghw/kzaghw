# Karim Zaghw

Source for Karim Zaghw's academic website, built with Jekyll and the Academic Pages theme.

The site is deployed to [kzaghw.github.io/kzaghw](https://kzaghw.github.io/kzaghw/) through GitHub Actions. Public content lives primarily in `_pages/` and `_publications/`; the downloadable CV is `files/Karim_Zaghw_CV.pdf`.
